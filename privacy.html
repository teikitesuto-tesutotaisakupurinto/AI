\

AI学習チャット プライバシーについて\

\
最終更新日：2026年11月 \
\

1. 基本方針\

\

定期テスト対策プリント運営事務局（以下「運営事務局」といいます）は、AI学習チャットを利用する皆さまの情報を適切に取り扱うことを重要と考えています。 \

\

本ページでは、AI学習チャットの利用に関連して取り扱われる情報について説明します。 \

\

2. AI学習チャットについて\

\

AI学習チャットは、国語・数学・社会・理科・英語などの学習をサポートするためのサービスです。 \

\

利用者が入力した質問や、学習のために送信した画像などを利用して、AIが回答を生成します。 \

\

3. 取り扱う可能性がある情報\

\

本サービスでは、サービスの提供に必要な範囲で、以下のような情報が送信される場合があります。 \

\
    \
  • 利用者が入力した質問や文章\
    • \
  • AIとのチャット内容\
    • \
  • 利用者が送信した問題や答案などの画像\
    • \
  • 選択した教科や利用モード\
    • \
  • AIとのやり取りに必要な学習状態\
    • \
  • サービスの動作に必要な技術情報\
    • \
\

4. 個人情報について\

\

本サービスを利用する際には、必要のない個人情報を入力・送信しないでください。 \

\

特に、氏名、住所、電話番号、学校名などの個人情報や、顔が写った写真は送信しないでください。 \

\

問題や答案を撮影して送信する場合も、個人情報が写り込んでいないことを確認してください。 \

\

5. 学習内容の取り扱い\

\

利用者がAI学習チャットに入力した質問、回答、画像などは、AIによる回答を提供するために処理されます。 \

\

利用者は、送信する内容が学習サポートに必要な範囲のものであることを確認してください。 \

\

6. AIサービスへの送信\

\

AI学習チャットでは、AIによる回答を生成するため、利用者が入力した質問や必要な画像などを、サービスの提供に必要な外部AIサービスへ送信する場合があります。 \

\

外部AIサービスへ送信される情報は、AI学習チャットの回答を生成するために必要な範囲で取り扱います。 \

\

7. APIキー等の情報\

\

AI学習チャットの運営に使用するAPIキーなどの認証情報は、利用者に公開される画面やプログラムに直接表示しないよう管理します。 \

\

利用者がAPIキーなどの内部情報を知る必要はありません。 \

\

8. チャット内容について\

\

AI学習チャットでは、回答を生成するために現在の会話内容や必要な過去の会話内容を処理する場合があります。 \

\

サービスの構成や設定によって、チャット内容の保存方法や保存期間が変更される場合があります。 \

\

9. 画像について\

\

問題や答案などの画像を送信する場合、その画像はAIが内容を確認し、回答や添削を行うために処理されます。 \

\

利用者は、必要のない個人情報が写った画像を送信しないようにしてください。 \

\

10. ログ・技術情報\

\

サービスの安定した運用や障害の確認、安全対策のため、アクセスに関する技術情報やエラー情報が記録される場合があります。 \

\

これらの情報は、サービスの運営、保守、障害対応、安全性の確保などの目的で利用します。 \

\

11. 情報の利用目的\

\

取り扱う情報は、主に以下の目的で利用します。 \

\
    \
  • AIによる学習サポートの提供\
    • \
  • 質問や答案の確認・添削\
    • \
  • サービスの維持・運用\
    • \
  • 障害や不具合の確認\
    • \
  • 不正利用やセキュリティ上の問題への対応\
    • \
  • サービスの改善\
    • \
\

12. 情報の共有\

\

運営事務局は、法令に基づく場合などを除き、利用者の情報を不必要に第三者へ提供しないよう取り扱います。 \

\

ただし、AIによる回答を提供するために必要な外部サービスなど、本サービスの運営に必要なサービス提供者へ情報が送信される場合があります。 \

\

13. セキュリティ\

\

運営事務局は、取り扱う情報について、不正アクセス、漏えい、紛失などを防ぐため、必要な安全対策を行うよう努めます。 \

\

ただし、インターネット上のサービスであるため、すべてのリスクを完全に防止できることを保証するものではありません。 \

\

14. 利用者による情報の管理\

\

利用者自身も、送信する情報について十分に注意してください。 \

\

特に、個人情報、他人の情報、顔写真などを必要なく送信しないでください。 \

\

15. 未成年者による利用\

\

本サービスは、中学生などの未成年者が学習目的で利用することを想定しています。 \

\

利用者は、サービスの利用にあたり、利用規約や本ページの内容を確認してください。 \

\

保護者の方から本サービスについて確認が必要な場合は、定期テスト対策プリント運営事務局へお問い合わせください。 \

\

16. 外部サービス\

\

本サービスでは、AIによる回答生成、サーバー運用、通信などのために外部サービスを利用する場合があります。 \

\

外部サービスを利用する場合、そのサービスの提供に必要な情報が送信されることがあります。 \

\

17. 情報の保存\

\

情報の保存方法、保存期間、削除方法などは、本サービスのシステム構成や運営上の必要性に応じて定めます。 \

\

保存が必要なくなった情報については、適切な方法で削除するよう努めます。 \

\

18. サービスの変更\

\

本サービスの機能追加や変更に伴い、情報の取り扱い方法が変更される場合があります。 \

\

重要な変更がある場合は、本ページなどを通じて案内します。 \

\

19. 本ページの変更\

\

運営事務局は、必要に応じて本ページの内容を変更することがあります。 \

\

変更後の内容は、本ページに掲載した時点から適用されます。 \

\

20. お問い合わせ\

\
\お問い合わせ・確認先\\
